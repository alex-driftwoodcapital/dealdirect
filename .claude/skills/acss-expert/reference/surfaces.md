## Backgrounds
- Contextual: `.bg--light` (`--bg-light`), `.bg--ultra-light` (`--bg-ultra-light`), `.bg--dark` (`--bg-dark`), `.bg--ultra-dark` (`--bg-ultra-dark`). Colors set in dashboard Color Assignments > Backgrounds (Website/Body, Dark, Ultra Dark, Light, Ultra Light). Auto foreground relationships (heading, text, link, link hover, button bg, icon, focus) configured in Color Assignments > Light/Dark Relationships; toggle in Options > Defaults & Misc.
- Surfaces (new in 4.0): Surfaces & Overlays > Custom Surfaces, up to 5. Class `.surface-{name}` (default `.surface-1`..); var `var(--surface-1)`, e.g. `background: var(--surface-1);`. Options: name, background color (fallback), asset (image URL / gradient / pattern), "Asset is URL" (adds `url()`), size, position, attachment (scroll|fixed|local), repeat, color relationship (ultra-light|light|ultra-dark|dark), animation (CSS shorthand; define `@keyframes` yourself), overlay (enable, color, opacity).
- `.is-bg`: makes element the background of its parent (position absolute, size = parent, z-index -2; parent gets `position: relative` + `isolation`). Tokens (default): `--bg-position` (absolute), `--bg-inset` (0), `--bg-width` (100%), `--bg-height` (100%), `--bg-radius` (0), `--bg-z-index` (-2), `--bg-object-fit` (cover, images only), `--bg-object-position` (center, images only). A blank `.is-bg` box after an `.is-bg` image acts as overlay. Unchanged in 4.0.

## Borders & radius
- Radius: `var(--radius)` (set 0 if none). Concentric: recipe `?concentric-radius`. Auto radius: "Add Radius Automatically" + quoted comma-separated selectors (default `img`, `figure` without images).
- Border tokens: `var(--border)` (shorthand), `var(--border-light)`, `--border-size`, `--border-style`, `--border-color-light`, `--border-color-dark`; page example also uses `--border-width`. Radius is not part of `--border`:
```
.card { border: var(--border); border-radius: var(--radius); }
.card { --border-width: 5px; border: var(--border-width) var(--border-style) var(--border-color-dark); }
```
- Removed in 4.0: `.border`, `.border-dark`, `.border-light` classes. Border colors use `color-mix()`.
- Mixin (Custom SCSS): `@include border($style, $position, $radius);` defaults: global style, `null` (all sides), `var(--radius)`. e.g. `@include border(light, block-start, var(--radius-l));` `@include border($radius: no);`

## Dividers
- `var(--divider)` (use with border), `var(--divider-dark)`, `--divider-inline-size`, `--divider-size`, `--divider-style`, `--divider-color-dark`, `var(--divider-gap)`. e.g. `border-block-end: var(--divider);`
- Recipes: `?divider-top`, `?divider-bottom`, `?divider-all` (margin-based between direct children; set parent gap to 0 if flex/grid).
- Local override: `#unique-element { --divider: var(--divider-size) var(--divider-style) var(--accent); }`
- Removed 4.0: `.divider-top`, `.divider-bottom`, `.divider--all`.

## Inverted radius (off by default: Borders & Dividers > Additional Radius Options > Inverted Radius Support)
- Define `--bg` on parent: `.this-section { --bg: var(--primary-light); background-color: var(--bg); }`
- Attributes on the box: `data-inverted-radius-1-position`, `data-inverted-radius-1-slice`, `data-inverted-radius-2-position`, `data-inverted-radius-2-slice` (max 2 corners).
- Position values (16): `top-left top-outside-left top-left-outside top-outside-left-outside top-right top-outside-right top-right-outside top-outside-right-outside bottom-left bottom-outside-left bottom-left-outside bottom-outside-left-outside bottom-right bottom-outside-right bottom-right-outside bottom-outside-right-outside`. Slice values: `top-left top-right bottom-left bottom-right`.
```
<div class="my-box" data-inverted-radius-1-position="bottom-left-outside" data-inverted-radius-1-slice="bottom-right" data-inverted-radius-2-position="bottom-right-outside" data-inverted-radius-2-slice="bottom-left"></div>
```
- Tokens: `--inverted-radius-[#]-position`, `-slice`, `-shadow`; values `var(--position-top-right-outside)`, `var(--slice-bottom-left)`, `var(--shadow-bottom-left)` (slice and shadow match).
- Artifact fix: `transform: translate3d(0,0,0);` on image. No gradient/texture parent support. Clickable parent: link must wrap, not be, the inverted-radius box.

## Shadows (Shadows panel; 5 slots each; custom names change the var)
- `var(--box-shadow-1..5)` (4,5 empty by default), `var(--text-shadow-1..5)`, `var(--drop-shadow-1..5)`; named: `var(--box-shadow-subtle)`. Use `box-shadow:`, `text-shadow:`, `filter: var(--drop-shadow-1)` (ACSS wraps value in `drop-shadow()`; enter raw values in dashboard). Disable: Options > Box/Text/Drop Shadow Variables.
- Defaults: text 1 `0 1px 2px hsl(0 0% 0% / 0.2)`, 2 `0 2px 4px hsl(0 0% 0% / 0.3)`, 3 `0 4px 8px hsl(0 0% 0% / 0.4)`; drop 1 `0 1px 2px hsl(0 0% 0% / 0.15)`, 2 `0 4px 6px hsl(0 0% 0% / 0.2)`, 3 `0 10px 15px hsl(0 0% 0% / 0.25)`.
- Removed 4.0: `.box-shadow--m` etc. Names were m/l/xl, now 1/2/3.

## Overlays
- Basic: Surfaces & Overlays > Basic Overlays. Class `.overlay` or any class containing `overlay--` (e.g. `.overlay--dark`). Vars: `--overlay-color` (default `rgba(0, 0, 0, 0.7)`), `--overlay-z-index` (default -1; `figure` with media gets 0). Pseudo-element `::before` (default) or `::after`. Uses `position:relative; z-index:0; isolation:isolate`.
- Custom (up to 5; Custom Overlays): classes `.overlay-1` or `.overlay-[name]`. Options: name, bg color, bg type (gradient|image|none), asset, size, position, attachment, repeat, backdrop blur, blend mode, opacity (default 0.7), radius, animation, inset (0).
  Global vars (each also as `--overlay-[n]-...`): `--overlay-bg-color`, `--overlay-background`, `--overlay-background-size`, `--overlay-background-position`, `--overlay-background-repeat`, `--overlay-background-attachment`, `--overlay-background-blur`, `--overlay-opacity`, `--overlay-blend-mode`, `--overlay-border-radius`, `--overlay-animation`, `--overlay-inset`, `--overlay-z-index`.
- Texture mixins (Custom SCSS): `@include texture(1);` `@include texture-overlay(1);` (numbered only; needs "Enable Overlay Class").

## Effects (opt-in via Effects > Options; respect prefers-reduced-motion; `-all` variants animate direct children; classes composable)
- Hover `.on-hover--`: `grow shrink float sink slide-right slide-left shadow glow brighten fade ripple-out ripple-in outline-out outline-in underline-left underline-center underline-right`. Vars: `--hover-grow-amount`, `--hover-float-amount`, `--hover-shadow`, `--hover-glow-color`, `--hover-glow-spread`, `--hover-glow-opacity`, `--border-ripple-color|width|duration|distance`, `--border-outline-color|width|duration`, `--border-underline-color|width|duration`, `--hover-duration` (`var(--transition-duration, 0.3s)`), `--hover-timing` (`var(--transition-timing, ease-in-out)`).
- Entrance `.on-enter--` (CSS scroll-driven; Chrome/Edge 115+): `fade float sink slide-left slide-right grow shrink blur parallax`. Children `.on-enter-all--{effect}`; `.on-enter--stagger` (uses `sibling-index()`, default 5% of range). Vars: `--animate-range-start` (`entry 20%`), `--animate-range-end` (`entry 100%`), `--enter-opacity-start`, `--enter-float-distance`, `--enter-sink-distance`, `--enter-slide-distance`, `--enter-scale-start`, `--enter-scale-shrink`, `--enter-blur-amount`, `--enter-parallax-distance` (parent needs `overflow: hidden`).
- Exit `.on-exit--`: `fade float sink slide-left slide-right grow shrink blur`; `.on-exit-all--{effect}`; `.on-exit--stagger`. Vars: `--exit-range-start` (`cover 50%`), `--exit-range-end` (`cover 100%`), `--exit-opacity-target`, `--exit-float-distance`, `--exit-sink-distance`, `--exit-slide-distance`, `--exit-blur-amount`, `--exit-scale-grow`, `--exit-scale-amount`.
- On Visible `.on-visible--` (JS Intersection Observer, adds `acss-visible`, plays once): `fade float sink slide-left slide-right grow shrink blur`; `.on-visible-all--{effect}`; `.on-visible--stagger` (default 0.1s). Vars: `--visible-duration` (0.6s), `--visible-timing` (`var(--ease-smooth)`), `--visible-delay` (0s), `--visible-threshold` (0.2), `--visible-opacity-start`, `--visible-float-distance`, `--visible-sink-distance`, `--visible-slide-distance`, `--visible-scale-start`, `--visible-scale-shrink`, `--visible-blur-amount`. Manual control: attribute `data-skip-acss-visible`, toggle class `acss-visible` via JS.
- Easing (5 nameable slots): `--ease-smooth` `cubic-bezier(0.4, 0, 0.2, 1)`, `--ease-snappy` `cubic-bezier(0.16, 1, 0.3, 1)`, `--ease-gentle` `cubic-bezier(0.65, 0, 0.35, 1)`, `--ease-bouncy` `cubic-bezier(0.68, -0.55, 0.265, 1.55)`, `--ease-elastic` (CSS `linear()`).
- Transition: `var(--transition)` (= duration timing delay): `transition: background var(--transition);` Granular: `var(--transition-duration)`, `var(--transition-timing)`, `var(--transition-delay)`. Local override must use granular vars (`--transition` is precomputed). `.transition` class removed in 4.0. Toggle "Transition Variables".
- Sticky: `.sticky` (`position: sticky; inset-block-start: var(--sticky-offset, 0)`), `--sticky-offset`, `.sticky-top--s|m|l` (Additional Styling > Sticky Settings). Removed 4.0: position utilities (`.relative` etc.), z-index utilities (`.z--10` etc.).
- Selection: `.selection--alt` on a box (alternate selection style; Additional Styling > Selection Styling).
- Gradient fades: classes `.fade--block|inline|top|right|bottom|left` (Options > Utility Classes > Fade Classes), var `--fade-amount` (e.g. 35%); mixin `@include fade($axis, $amount)` (default 25%); recipes `?fade-block; ?fade-inline; ?fade-top; ?fade-right; ?fade-bottom; ?fade-left;` (must type the semicolon to expand).

## Elements
- Blockquote (4.0): auto-styles `<blockquote>` (toggle "Auto Style Blockquotes"; off => `.blockquote` class, placed on `<figure>` if figure-wrapped). "Exclude Selectors" textarea. Vars: `--blockquote-padding --blockquote-gap --blockquote-border-width --blockquote-border-style --blockquote-border-color --blockquote-border-radius --blockquote-background --blockquote-box-shadow --blockquote-max-inline-size`; text (on inner `<p>`): `--blockquote-text-color|font-family|font-style|font-size|font-weight|line-height|align|transform`; footer: `--blockquote-footer-padding|margin-block|font-family|font-size|font-weight|font-style|line-height|text-transform|color`; cite: `--blockquote-cite-font-size|font-weight|font-style|line-height|text-transform|color`. Defaults: padding `var(--space-m)`, border `0 0 0 3px` solid `var(--primary)`, radius `var(--radius)`, bg `var(--neutral-ultra-light)`, text size `var(--text-l)`, footer size `var(--text-s)`.
- Ribbons: container `position: relative; overflow: hidden`; text element `.ribbon` + `.ribbon--top-right` / `.ribbon--top-left`; dynamic `data-ribbon-position="top-right|top-left"`, custom style attr e.g. `[data-ribbon-style="sale"]`. Vars: `--ribbon-offset` (-2rem), `--ribbon-width` (30rem), `--ribbon-padding` (.5em 1em), `--ribbon-background-color`, `--ribbon-text-color`, `--ribbon-text-size` (`var(--text-s)`), `--ribbon-shadow`. Page lists default colors as `var(--action)`, `var(--white)`, `--shade-trans-10` (3.x-era names; verify in 4.x).
