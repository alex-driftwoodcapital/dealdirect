# ACSS index (read-only reference, never deployed)
- `automatic.css`, `acss-settings.json`: compiled stylesheet and settings export from staging (ACSS 4.0.1). Refreshed by hand per site.
- `acss-index.json`: flat name list generated by `scripts/build-index.py`.

Entry: `{name, kind: variable|class|recipe|absent, group, status: present|documented|absent, since, doc, replacement, pattern}`.
- `present`: found in the compiled stylesheet (variables from `:root`, classes from selectors). Group = the stylesheet's own `/* Feat: ... */` section; `doc` = official docs page.
- `documented`: `?recipes` from the 4.x docs; recipes expand in the builder, so they cannot be checked in compiled CSS.
- `absent`: names the docs (or ACSS 3.x) show but the build does not output; `pattern` is a regex, `replacement` says what to use. Source: the table in `reference/staging-4.0.1-facts.md`. Lookup rule: match `present` first, then `absent`.

## Refresh (on an ACSS update or a new site)
1. Re-export `automatic.css` (`wp acss css regenerate`, copy `wp-content/uploads/automatic-css/automatic.css`) and the settings (`wp acss settings export`) into `index/`.
2. `python3 -I scripts/build-index.py` (stdlib only; `--css`/`--out` for another site).
3. `git diff index/acss-index.json`: review added/removed names; update the "absent" table in the facts file for new removals, then re-run.
